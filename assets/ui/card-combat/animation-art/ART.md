# Animation art generation

Generated with the built-in image-generation tool on 20 October 2026. Each asset came from a separate transparent-image generation, using existing Arkflight raster artwork as finish references. PNG sources remain in the creation session; the module receives WebP exports at quality 70 with unchanged dimensions and alpha.

Reference artwork already present in the module:

- `assets/ui/panels/ui_panel_frame_corner_top_left.webp`
- `assets/ui/stations/station_icon_engineer.webp`
- `assets/ui/stakes/event_stake_icon_lifeveil.webp` (Lifeveil palette and motif)

The prompts describe the intended generation. Integration notes and the manifest describe the exported assets; no animation behavior is implemented by this art pack.
