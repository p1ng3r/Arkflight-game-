# Crew Command banner

`command-banner.webp` was generated using the built-in imagegen tool in generation mode on 17 October 2026, then encoded as WebP for the module. The interface uses existing Arkflight station and equipment assets for card art; no card behavior is derived from imagery.

Final prompt:

> Create a cinematic wide landscape background banner for a fantasy tabletop ship combat command board. Arkflight: an ornate wooden sailing warship with cream canvas sails, brass fittings and glowing cyan Arkengine crystals flying through deep navy outer space, a second distant enemy ship amid floating asteroid fragments. Broadside cannons firing a few vivid amber shots, magical cyan wake, epic but elegant painterly game concept art, tactile wood and brass. Main detailed vessel occupies right two thirds, left third is quiet dark navy starfield with subtle nebula, suitable for gold interface text overlay. Restrained gold and cyan palette, strong readable silhouette. No text, letters, logos, UI panels or borders. Very wide composition, landscape 3:1.
