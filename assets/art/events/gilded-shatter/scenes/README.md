# Gilded Shatter Scene Art

Scene art for **The Gilded Shatter** is organized by adventure leg so Foundry paths stay predictable.

## 01 — Boarding
`assets/art/events/gilded-shatter/scenes/01-boarding/`

Use for the opening approach and the three-round boarding Event.

Suggested filenames:
- `opening-gilded-shatter.webp`
- `round-1-close-on-the-wreck.webp`
- `round-2-competing-vectors.webp`
- `round-3-loaded-boarding-lines.webp`
- `boarding-established.webp`

## 02 — Wreck Exploration
`assets/art/events/gilded-shatter/scenes/02-wreck-exploration/`

Use for PF2e exploration vignettes, discoveries, deck transitions, and encounter art after the PCs board.

## 03 — Salvage & Escape
`assets/art/events/gilded-shatter/scenes/03-salvage-escape/`

Use for the second Arkflight Event line: deep salvage, greed choices, collapse, and escape from the Dark Star.

Prefer lowercase kebab-case filenames and WebP for final Foundry assets.
